CATÁLOGO DE CARRERAS UASD

1. Descripción del proyecto

El proyecto Catálogo de Carreras UASD es un sistema desarrollado en Java que tiene como finalidad
organizar y facilitar la consulta de información relacionada con las carreras universitarias. El 
sistema utiliza una base de datos SQLite para almacenar la información.

2. Objetivo general

Desarrollar un sistema informático que permita organizar y consultar información de las carreras
universitarias de la Universidad Autónoma de Santo Domingo (UASD).

3. Tecnologías utilizadas

* Lenguaje de programación: Java.
* Entorno de desarrollo: Apache NetBeans.
* Base de datos: SQLite.
* Sistema de compilación: Apache Ant.

4. Requisitos para ejecutar el proyecto

Para ejecutar el sistema se necesita:

* Una computadora con Windows.
* Java Development Kit (JDK) compatible con el proyecto.
* Apache NetBeans.
* Archivos del proyecto y su base de datos.

5. Dependencias

El proyecto utiliza:

* Java JDK.
* SQLite.
* Apache NetBeans.

El controlador JDBC debe estar agregado a las bibliotecas del proyecto para permitir
la conexión con la base de datos.

6. Instalación

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir Apache NetBeans.
3. Seleccionar la opción Open Project (Abrir proyecto).
4. Buscar la carpeta CatalogoCarrerasUASD.
5. Abrir el proyecto.
6. Verificar que las bibliotecas y dependencias estén configuradas correctamente.
7. Comprobar que la base de datos esté disponible.

7. Ejecución del sistema

1. Abrir el proyecto en Apache NetBeans.
2. Identificar la clase principal del programa.
3. Ejecutar el proyecto utilizando la opción Run Project.
4. Verificar que el sistema funcione correctamente.

8. Base de datos

El proyecto utiliza una base de datos SQLite llamada:
catalogo_uasd.db
Esta base de datos almacena la información utilizada por el sistema.
